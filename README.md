# Send Him to Dagestan — спортивно-туристические «лагеря закалки»

## Тема
Сайт сервиса добровольной записи подростков (13–17 лет) на спортивно-туристические смены на Кавказе: горный треккинг, борьба и ОФП, медиашкола. Упор на безопасность, согласие родителей и наставничество.

## Структура страниц
- index.html — главная (Hero, кратко о проекте, навигация).
- programs.html — направления: треккинг, борьба и ОФП, медиашкола (списки/ol/ul).
- how-it-works.html — этапы набора, сниппет кода (`pre > code`), цитата (`blockquote`/`cite`).
- apply.html — форма заявки (`form`, fieldset, input, `textarea`).
- about.html — миссия, почему доверяют, как работаем.
- contacts.html — контакты (телефон, email, координаты).
